# CriptoPortfolio — Марковиц 2026

**Клиент-серверное приложение для оптимизации криптовалютного портфеля по модели Гарри Марковица.**
## Основные возможности

### Для обычных пользователей
- Регистрация и авторизация
- Ввод состава активов (пример: `BTC:0.01, TON:500`)
- Настройка целевого уровня риска
- **Оптимизация портфеля** по модели Марковица
- Визуализация результатов:
  - Круговая диаграмма структуры портфеля
  - Столбчатая диаграмма рыночной стоимости
- Сохранение портфеля в личном кабинете
- История сохранённых портфелей
- Экспорт отчёта в CSV

### Для администраторов
- Управление криптоактивами (цена, риск)
- Просмотр всех пользователей
- Принудительное отключение сессий
- Полное удаление пользователей (вместе с портфелями)

## Технологии

- **Java 21**
- **JavaFX** — графический интерфейс, графики, CSS-стилизация
- **Многопоточный TCP-сервер** (сокеты)
- **MySQL** + **JDBC**
- **Сериализация объектов** (`Request` / `Response`)
- **ConcurrentHashMap** — управление активными сессиями
- **Модель Марковица** — алгоритм оптимизации портфеля
